# 애니메이션 뷰어 PRD

## 목표

`pico2d`를 사용해 `sonic_animation_viewer.py` 하나의 파일로 소닉 스프라이트 애니메이션 뷰어를 만든다.

## 사용 리소스

- 소스 파일: `sonic_animation_viewer.py`
- 이미지 파일: `sonic-sprite.png`
- 개발 위치: `Labs/LEC09`

## 주요 기능

- 스프라이트 시트에 포함된 모든 동작 애니메이션을 순서대로 재생한다.
- 하나의 동작 애니메이션은 5번 반복 재생한다.
- 한 동작이 끝나면 1초 쉬고 다음 동작을 재생한다.
- 모든 동작 재생이 끝나면 처음 동작부터 다시 반복한다.
- 캐릭터가 잘 보이도록 화면 크기에 맞춰 충분히 확대해서 출력한다.

## 구현 방식

- `pico2d`의 이미지 출력 기능을 사용한다.
- 스프라이트 시트에서 각 프레임 영역을 잘라 화면에 그린다.
- 애니메이션 목록, 현재 동작, 현재 프레임, 반복 횟수를 코드에서 관리한다.
- 프로그램은 창을 닫기 전까지 계속 실행된다.

## 개발 진행 기준

- 한 번에 전체 기능을 완성하지 않고 단계별로 구현한다.
- 최소 20개 이상의 커밋이 나오도록 작은 단위로 나누어 개발한다.
- 각 커밋은 실행 가능한 상태를 유지하는 것을 목표로 한다.

## 완료 기준

- `sonic_animation_viewer.py` 실행 시 애니메이션 창이 열린다.
- 모든 동작 애니메이션이 순서대로 재생된다.
- 각 동작은 5회 반복 후 1초 대기한다.
- 마지막 동작 이후 다시 처음 동작으로 돌아가 반복 재생된다.
